MIDHA DENTAL CARE - STATIC WEBSITE DESIGN PREVIEW

This is Phase 1A: static front-end design only.
Built with HTML5, CSS3, responsive custom CSS, and JavaScript.

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Navigate through the pages using the top navigation.

PAGES
- index.html
- about.html
- services.html
- doctors.html
- gallery.html
- testimonials.html
- appointment.html
- contact.html

IMPORTANT
- This is a static prototype. Appointment and contact forms show a demo message only.
- No database, admin panel, authentication, or email delivery is connected yet.
- Doctor profiles, testimonials, and gallery photos are placeholders and must be replaced with clinic-approved content.
- Existing clinic name, tagline, contact details and location have been used as supplied/previously referenced; verify all details with Midha Dental Care before going live.
- Images and Google Fonts are loaded from external URLs, so an internet connection is needed to display them.
- The existing domain and live website have not been modified.

NEXT PHASE
After design approval, convert the pages into ASP.NET Core MVC views, create the database/admin panel, and connect appointment requests.
