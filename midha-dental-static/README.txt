MIDHA DENTAL CARE — MODERN STATIC WEBSITE

Pages:
- index.html (Home)
- about.html
- services.html
- doctors.html
- blog.html
- gallery.html
- appointment.html
- contact.html

How to preview:
1. Extract this folder.
2. Open index.html in a browser, or use Visual Studio Code Live Server.

How to publish on GitHub Pages:
1. Extract the ZIP.
2. Upload the CONTENTS of the midha-dental-modern folder to the ROOT of your GitHub repository.
3. Ensure index.html is at repository root.
4. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Wait for deployment, then open your GitHub Pages URL.

Important:
- This is a static design prototype. Appointment/contact forms do not send or store data.
- Doctor names, qualifications, clinic photos, opening hours, services and all medical copy should be checked and approved by Midha Dental Care before launch.
- Images and Google Fonts load from external services and require internet access.
- Existing website/domain is not modified by this package.
- Later this design can be converted into ASP.NET Core MVC with SQL Server and a secure admin panel.

SVG ICONS:
- Interface icons are stored as individual files in assets/icons/ and reused across pages.
- Decorative Unicode icon glyphs have been replaced with SVG icons for a consistent visual style.

ICON CLEANUP:
- Decorative Unicode symbols (arrows, stars, plus signs and similar glyphs) are removed or replaced with SVG assets.
- Useful phone, email and location icons remain SVG-based.
- SVG assets are stored in assets/icons/.
